Pebble 16-color radar palette tool (1 transparent + 15 data)

Serve repo root (python3 -m http.server) then open palette_tool/index.html. Gray assets decode: g<128 → rain, dBZ=g-32; g≥128 → snow, dBZ=g-160; alpha 0 → transparent. Low end hides (dBZ < start → transparent); high end clamps to top band. dBZ boost previews stronger/weaker weather (transparent + snow-backdrop gray 128 never boosted). Dither mixes band[i] ↔ band[i+1] (and transparent ↔ band 0) via 2x2 Bayer on boosted dBZ. BW mode dithers each phase's range to a shared transparent/opaque ramp (black, white when dark) with 2x2 or 4x4 Bayer.
